LC Phonehack

Repository Download

Hack the phones of NPCs nearby. lc_phonehack adds phones to LC Hack's laptop: when the player runs scan on it, the phones of NPCs nearby show up, and connect connects to one. Then the player logs in, finds the phone's PIN in its files and uses it with su.

It is also an example of how to build on LC Hack: one small file with registerDevice, see How it Works.

Installation

Install all resource dependencies

  • LC Hack 1.8.0 or newer (the laptop and registerDevice)
  • ox_lib
  • ox_inventory (optional, for the reward item)
  • OneSync with population (the default), so the server knows the NPCs.

Download a release or clone the source code

  • Download the latest release.
  • Or clone the repository: git clone https://github.com/LAURIDS0/lc_phonehack.git

Start the resource

Start lc_phonehack after lc_hack in your server.cfg.

ensure ox_lib
ensure lc_hack
ensure lc_phonehack

Add the items

Set up LC Hack's laptop item if you haven't. With ox_inventory, also add the reward to ox_inventory/data/items.lua.

['phone_data'] = {
    label = 'Phone Data',
    weight = 10,
},

Common Issues

Problems that come up when setting up lc_phonehack, and how to solve them.

scan never finds any devices

  • The server has to know the NPCs. Use OneSync with population (the default); with population turned off there are no NPCs on the server.
  • Only NPCs within range (default 25.0 meters) are listed, and only part of them carry a phone (chance).
  • Players and dead NPCs never show up.
  • lc_phonehack must be started after lc_hack. It adds the phones to the laptop when it starts, and again when lc_hack restarts.

"connect: ... is out of range"

The NPC walked away or the player moved after scan. Run scan again and connect to a device that is close.

The player got root but no reward

  • The NPC must still be within range when the player becomes root, and each connection gives its reward once.
  • The item is only added when ox_inventory is started. Without it, give rewards in onHacked.

The laptop doesn't open

The laptop belongs to LC Hack. With ox_inventory, the laptop item's server.export must be lc_hack.useLaptop; without ox_inventory, players use /laptop. See LC Hack's laptop.

Config

Everything is in config.lua in the resource folder. It is only loaded on the server. Restart the resource after changing it.

The laptop itself (its item, desktop, wrong PINs allowed and how many devices scan lists) is set up in LC Hack's config.

range

  • range: number
    • How far away (meters) a phone can be found with scan, and how close the NPC must stay to connect and to get the reward. Defaults to 25.0.

chance

  • chance: number
    • Part of the NPCs that carry a phone, from 0.0 to 1.0. The same NPC always gives the same answer. Defaults to 0.6.

cooldown

  • cooldown: number
    • Seconds before a hacked phone can be hacked again. It shows as locked meanwhile. Defaults to 600.

reward

  • reward: table or false
    • The item a hacked phone gives, when ox_inventory is started.
    • item: string
      • Defaults to 'phone_data'.
    • count?: number
      • Defaults to 1.

onHacked

  • onHacked: function(source: number, device: string)
    • Called on the server for every hacked phone, with or without ox_inventory. device is the phone's name, e.g. 'Pixel-8c13'.

Example

onHacked = function(source, device)
    -- Give money with your framework, alert the police, ...
    print(('%s hacked %s'):format(GetPlayerName(source), device))
end,

Playing

What the player does, from opening the laptop to the reward.

Open the laptop

Use the laptop item, or /laptop without ox_inventory. help lists scan and connect under "Tools", and ~/Desktop/README.txt explains them.

Scan for phones

scan lists every device nearby, closest first: the phones of NPCs, and whatever other resources add to the laptop, like vehicles from LC Keyclone. Walk closer to people for more phones.

ID  TYPE      DEVICE              SIGNAL    STATUS
1   phone     Pixel-8c13          -41 dBm   available
2   vehicle   KEY-9732            -46 dBm   available
3   phone     Galaxy-cce4         -52 dBm   locked

locked phones were hacked a moment ago and can't be hacked yet.

Connect

connect 1 connects to the phone and tells its IP. Log in with ssh mobile@<ip>; no password is needed.

Find the PIN

The PIN is somewhere in the phone's files: a note, a message, a settings file or a hidden file. Look around with ls -a, cat, grep and find. Careful: an old PIN is there too, and a wrong PIN costs an attempt.

Become root

Run su and type the PIN. The player gets the reward, and the laptop stays open for the next phone.

How it Works

lc_phonehack is a device type for LC Hack's laptop: it has no laptop, item or terminal of its own. It is a good starting point for your own, see Creating a Hack Type.

The device type

When it starts, lc_phonehack calls registerDevice once. LC Hack's scan calls its scan, and connect calls its connect:

exports.lc_hack:registerDevice('phone', {
    -- The phones of the NPCs near the player
    scan = function(source)
        return { { id = netId, name = 'Pixel-8c13', distance = 6.2, locked = false } }
    end,

    -- The phone as a machine, or why it can't connect
    connect = function(source, netId)
        if not nearbyNpc(source, netId) then return 'Pixel-8c13 is out of range.' end
        return {
            user = 'mobile',
            rootPassword = pin,
            files = phones.files(pin),
            onRoot = function(player)
                reward(player, netId)
            end,
        }
    end,
})

LC Hack keeps the list, gives the phone an IP on the laptop's network and adds it to the hack. The phone's user has no password, and its root password is the PIN hidden in its files. onRoot gives the reward.

LC Hack forgets device types when it restarts, so lc_phonehack registers again on onResourceStart for lc_hack.

Security

Everything runs and is checked on the server; the client only shows the terminal.

  • scan reads the NPCs near the player on the server. Players and dead NPCs are skipped.
  • connect checks that the NPC still exists, is alive, within range and not on cooldown.
  • The PIN stays on the server like every password in LC Hack; every attempt is checked there.
  • The reward is given in onRoot, once per connection, and only while the NPC is still within range.
