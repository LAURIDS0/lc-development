LC Phonehack

Repository Download

Hack the phones of NPCs nearby with a laptop. The player gets LC Hack's terminal and desktop with two extra commands: scan finds phones nearby, and connect connects to one. Then the player logs in, finds the phone's PIN in its files and uses it with su.

Installation

Install all resource dependencies

  • LC Hack 1.4.0 or newer
  • ox_lib
  • ox_inventory (optional, a command opens the laptop without it)
  • OneSync with population (the default), so the server knows the NPCs.

Download a release or clone the source code

  • Download the latest release.
  • Or clone the repository: git clone https://github.com/LAURIDS0/lc_phonehack.git

Start the resource

Start lc_phonehack after lc_hack in your server.cfg.

ensure ox_lib
ensure lc_hack
ensure lc_phonehack

Add the items

With ox_inventory, add the laptop and the reward to ox_inventory/data/items.lua. consume = 0 keeps the laptop when it's used.

['hacking_laptop'] = {
    label = 'Hacking Laptop',
    weight = 1500,
    stack = false,
    consume = 0,
    server = { export = 'lc_phonehack.useLaptop' },
},

['phone_data'] = {
    label = 'Phone Data',
    weight = 10,
},

Without ox_inventory, players open the laptop with /laptop, see command.

Common Issues

Problems that come up when setting up lc_phonehack, and how to solve them.

scan never finds any devices

  • The server has to know the NPCs. Use OneSync with population (the default); with population turned off there are no NPCs on the server.
  • Only NPCs within range (default 25.0 meters) are listed, and only part of them carry a phone (chance).
  • Players and dead NPCs never show up.

"connect: ... is out of range"

The NPC walked away or the player moved after scan. Run scan again and connect to a device that is close.

The player got root but no reward

  • The NPC must still be within range when the player becomes root, and each connection gives its reward once.
  • The item is only added when ox_inventory is started. Without it, give rewards in onHacked.

/laptop doesn't exist

The command is only added when ox_inventory isn't started. With ox_inventory, players use the hacking_laptop item instead.

Config

Everything is in config.lua in the resource folder. It is only loaded on the server. Restart the resource after changing it.

range

  • range: number
    • How far away (meters) a phone can be found with scan, and how close the NPC must stay to connect and to get the reward. Defaults to 25.0.

chance

  • chance: number
    • Part of the NPCs that carry a phone, from 0.0 to 1.0. The same NPC always gives the same answer. Defaults to 0.6.

maxDevices

  • maxDevices: number
    • Most devices scan lists, closest first. Defaults to 8.

cooldown

  • cooldown: number
    • Seconds before a hacked phone can be hacked again. It shows as locked meanwhile. Defaults to 600.

attempts

  • attempts: number
    • Wrong passwords and PINs allowed in one laptop session. The laptop closes when they run out. Defaults to 4.

desktop

  • desktop: string or false
    • The laptop's desktop, one of LC Hack's desktops, or false for a terminal only. Defaults to 'kali'.

item

  • item: string
    • The ox_inventory item that opens the laptop. Point the item's server.export to lc_phonehack.useLaptop. Defaults to 'hacking_laptop'.

command

  • command: table or false
    • A command that opens the laptop when ox_inventory isn't started. false for none.
    • name: string
      • Defaults to 'laptop'.
    • restricted?: string or false
      • An ace the player needs, e.g. 'group.admin'. false for everyone.

reward

  • reward: table or false
    • The item a hacked phone gives, when ox_inventory is started.
    • item: string
      • Defaults to 'phone_data'.
    • count?: number
      • Defaults to 1.

onHacked

  • onHacked: function(source: number, device: string)
    • Called on the server for every hacked phone, with or without ox_inventory. device is the phone's name, e.g. 'Pixel-8c13'.

Example

onHacked = function(source, device)
    -- Give money with your framework, alert the police, ...
    print(('%s hacked %s'):format(GetPlayerName(source), device))
end,

Server

openLaptop

Opens the laptop for a player, e.g. from your own item, job or command.

exports.lc_phonehack:openLaptop(source)
  • source: number

Return:

  • boolean - Returns false if the player is already hacking.

Example

RegisterCommand('hackphones', function(source)
    if not exports.lc_phonehack:openLaptop(source) then
        TriggerClientEvent('ox_lib:notify', source, { type = 'error', description = 'You are busy.' })
    end
end, true)

useLaptop

The ox_inventory item export. Point the laptop item's server.export to it; you don't call it yourself. It opens the laptop and keeps the item.

server = { export = 'lc_phonehack.useLaptop' },

Playing

What the player does, from opening the laptop to the reward.

Open the laptop

Use the hacking_laptop item, or /laptop without ox_inventory. help lists the new commands under "Tools", and ~/Desktop/README.txt explains them.

Scan for phones

scan lists the phones of NPCs nearby, closest first. Walk closer to people for more devices.

ID  DEVICE          SIGNAL    STATUS
1   Pixel-8c13      -41 dBm   available
2   Galaxy-cce4     -52 dBm   available
3   Phone-1a7f      -63 dBm   locked

locked phones were hacked a moment ago and can't be hacked yet.

Connect

connect 1 connects to the phone and tells its IP. Log in with ssh mobile@<ip>; no password is needed.

Find the PIN

The PIN is somewhere in the phone's files: a note, a message, a settings file or a hidden file. Look around with ls -a, cat, grep and find. Careful: an old PIN is there too, and a wrong PIN costs an attempt.

Become root

Run su and type the PIN. The player gets the reward, and the laptop stays open for the next phone.

How it Works

lc_phonehack is a hack type built on LC Hack's building blocks. It is a good starting point for your own.

The laptop

The laptop is an LC Hack hack started with startHack. It has target = false, so it stays open until the player closes it, and two commands that run on the server:

exports.lc_hack:startHack(source, {
    ip = '172.20.0.1',
    host = 'laptop',
    desktop = 'kali',
    target = false,
    commands = {
        scan = scan,       -- function(source, args) returning the lines to print
        connect = connect,
    },
})

Phones

connect adds the phone to the hack with addMachine. It is on the laptop's network, its user has no password, and its root password is the PIN hidden in its files. onRoot gives the reward.

exports.lc_hack:addMachine(source, {
    ip = '172.20.0.2',
    host = 'Pixel-8c13',
    user = 'mobile',
    rootPassword = pin,
    files = phones.files(pin),
    onRoot = function(player)
        reward(player, netId)
    end,
})

Security

Everything runs and is checked on the server; the client only shows the terminal.

  • scan reads the NPCs near the player on the server. Players and dead NPCs are skipped.
  • connect checks that the NPC still exists, is alive, within range and not on cooldown.
  • The PIN stays on the server like every password in LC Hack; every attempt is checked there.
  • The reward is given in onRoot, once per connection, and only while the NPC is still within range.
