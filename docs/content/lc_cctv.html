LC CCTV

Repository Download

Hack a building's security room and turn its cameras off for a while. Every security room is a computer in the world with the camera server (NVR) behind it. Your other scripts (dispatch, police, cameras) can ask if a place is out of sight.

Installation

Install all resource dependencies

  • LC Hack 1.5.0 or newer
  • ox_lib

Download the resource

  • Download the latest version and unzip it as lc_cctv.
  • Or clone the repository: git clone https://github.com/LAURIDS0/lc_cctv.git

Start the resource

ensure ox_lib
ensure lc_hack
ensure lc_cctv

Try it

Run /cctvtest as an admin. It creates a test security room where you stand, with its cameras covering 50 meters around you for 60 seconds.

Next steps

  • Site: add your own security rooms.
  • Using it in Other Scripts: skip camera alerts while an area is blind.

Common Issues

"The cameras are already off."

The site was hacked a moment ago. Its cameras come back on after duration seconds.

"The security system is locked."

The site was hacked within cooldown seconds (default 1800), counted from the hack.

Cameras are off, but my dispatch still sends camera alerts

LC CCTV doesn't change other scripts by itself. Check isAreaBlind in your dispatch script, see Using it in Other Scripts.

The computer doesn't show

  • Check the site's coords. Without ox_target, it is an [E] point.
  • The server console prints a site needs a name and coords for sites that are missing them.

Config

Everything is in config.lua in the resource folder. It is only loaded on the server.

item

  • item: string or false
    • An ox_inventory item a player needs to use a security computer. false for none. Defaults to false.

attempts

  • attempts: number
    • Wrong passwords allowed per hack. Defaults to 3.

desktop

  • desktop: string or false
    • The guard's desktop, one of LC Hack's desktops, 'random', or false for a terminal only. Defaults to 'random'.

duration

  • duration: number
    • Seconds the cameras stay off. A site can set its own. Defaults to 300.

cooldown

  • cooldown: number
    • Seconds before a site can be hacked again, counted from the hack. A site can set its own. Defaults to 1800.

testCommand

  • testCommand: table or false
    • name (default 'cctvtest') and restricted (default 'group.admin'). false for none.

sites

  • sites: Site[]
    • The security rooms, see Site.

onDisabled

  • onDisabled: function(source: number, site: string, duration: number)
    • Called on the server when a site's cameras go off. source is nil when another script turned them off.

onRestored

  • onRestored: function(site: string)
    • Called on the server when the cameras come back on.

Site

Every security room is an entry in sites in config.lua.

sites = {
    {
        name = 'bank',
        label = 'Pacific Standard',
        coords = vec3(264.5, 219.8, 101.7),
        area = { coords = vec3(255.0, 225.0, 101.0), radius = 60.0 },
        cameras = 8,
        duration = 240,
    },
},

name

  • name: string
    • Unique and lowercase. Used in the hostnames (bank-nvr01) and by the exports.

label

  • label: string
    • The building's name.

coords

  • coords: vector3
    • Where the guard's computer is.

area

  • area?: { coords: vector3, radius: number }
    • The area its cameras cover. Defaults to 50 meters around coords.

cameras

  • cameras?: number
    • How many cameras the NVR lists. Only for the look. Defaults to 6.

duration and cooldown

  • duration?: number
    • Defaults to duration in the config.
  • cooldown?: number
    • Defaults to cooldown in the config.

desktop, radius and screen

  • desktop?: string or false
    • This site's desktop. Defaults to the config's.
  • radius?: number
    • How close the player must be to the computer.
  • screen?: table
    • An in-world screen that shows the hack, like LC Hack's screens.

Server

isAreaBlind

Checks if a position is inside an area whose cameras are off.

exports.lc_cctv:isAreaBlind(coords)
  • coords: vector3

Return:

  • boolean - Returns true if the position is out of sight.
  • string? - The site's name.

getBlindAreas

Every area whose cameras are off.

exports.lc_cctv:getBlindAreas()

Return:

  • { site, label, coords, radius, untilTime }[] - untilTime is the os.time() the cameras come back on.

disableCameras

Turns a site's cameras off from another script, e.g. after a power cut. It doesn't start the site's cooldown.

exports.lc_cctv:disableCameras(site, duration)
  • site: string
  • duration?: number
    • Seconds. Defaults to the site's duration.

Return:

  • boolean - Returns false if the site doesn't exist.

restoreCameras

Turns a site's cameras back on before the time is up.

exports.lc_cctv:restoreCameras(site)
  • site: string

Client

isBlind

Checks if a position is inside an area whose cameras are off.

exports.lc_cctv:isBlind(coords)
  • coords?: vector3
    • Defaults to the player's position.

Return:

  • boolean - Returns true if the position is out of sight.
  • string? - The site's name.

The same list is in GlobalState.lc_cctv.

Using it in Other Scripts

LC CCTV only says where the cameras are off; your other scripts decide what that means.

Skip camera alerts

Before your dispatch or robbery script sends a "seen on camera" alert, check the position:

local function sendCameraAlert(coords, message)
    if GetResourceState('lc_cctv') == 'started' and exports.lc_cctv:isAreaBlind(coords) then
        return -- the cameras are off here
    end
    -- send the alert as usual
end

Tell the police

Use onDisabled in the config, or the event:

AddEventHandler('lc_cctv:disabled', function(site, duration)
    -- e.g. a quiet alert: "Camera system offline at the bank"
end)

Show it to the player

RegisterNetEvent('lc_cctv:disabled', function(site, duration)
    if exports.lc_cctv:isBlind() then
        lib.notify({ description = ('Cameras off for %d seconds'):format(duration) })
    end
end)

Playing

Use the guard's computer

The shift notes on the desktop tell where the camera server (the NVR) is.

Find the NVR's login

Its web panel gives it away. Open it in the browser or with curl: the page source, the install notes it links to, or a note on the guard's desktop (in base64, base64 -d).

Log in

ssh admin@<nvr>. /etc/nvr/cameras.conf lists the cameras.

Find the root password and become root

It is on the NVR: in a config file, in the program itself (strings) or in the shell history. A backup with an old password is there too. Run su with it: the cameras go off.
