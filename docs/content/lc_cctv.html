LC CCTV

Repository Download

Break into a building's security room and watch its cameras live. The player finds the camera server's login, becomes root, reads the camera list and opens the cameras with view <ip>. Every camera opens in its own window, and several can be open at once.

Live and frozen

The game can only show one camera at a time. The window that was clicked last is live: the game shows that camera through it. The others freeze on their last picture with the time it was taken, until they are clicked. The last picture needs screenshot-basic; without it, a frozen window is black.

Installation

Install all resource dependencies

  • LC Hack 1.7.0 or newer
  • ox_lib
  • screenshot-basic (optional, for frozen windows)

Download the resource

  • Download the latest version and unzip it as lc_cctv.
  • Or clone the repository: git clone https://github.com/LAURIDS0/lc_cctv.git

Start the resource

ensure ox_lib
ensure screenshot-basic
ensure lc_hack
ensure lc_cctv

Try it

Run /cctvtest as an admin. It creates a security room where you stand, with four cameras around it looking at you.

Next steps

  • Placing Cameras: find the coords and rotation for your cameras.
  • Site: every field of a security room.

Common Issues

"view: ... Network is unreachable"

The cameras are on their own network. Log in to the NVR with ssh and run view from there.

"view: cannot open display"

Camera windows need a desktop. The guard's computer has one by default; on a machine without one, run startx first.

Frozen windows are black

The last picture is taken with screenshot-basic. Start it before lc_hack.

A camera looks the wrong way

rotation is vec3(pitch, roll, heading): the heading is the direction it looks, and a negative pitch looks down. See Placing Cameras.

The computer doesn't show

The server console prints a site needs a name, coords and cameras for sites that are missing them.

Config

Everything is in config.lua in the resource folder. It is only loaded on the server.

item

  • item: string or false
    • An ox_inventory item needed to use a security computer. Defaults to false.

attempts

  • attempts: number
    • Wrong passwords allowed per hack, including camera passwords. Defaults to 3.

desktop

  • desktop: string
    • The guard's desktop, one of LC Hack's desktops or 'random'. The camera windows need a desktop. Defaults to 'random'.

refresh

  • refresh: number or false
    • Seconds between new networks and passwords for every site, so players can't reuse old ones. Hacks paused at a terminal are lost when it happens. Defaults to 3600.

testCommand

  • testCommand: table or false
    • name (default 'cctvtest') and restricted (default 'group.admin').

sites

  • sites: Site[]
    • The security rooms, see Site.

Site

sites = {
    {
        name = 'bank',
        label = 'Pacific Standard',
        coords = vec3(264.5, 219.8, 101.7),
        cameras = {
            { label = 'Lobby', coords = vec3(240.2, 213.5, 110.5), rotation = vec3(-20.0, 0.0, 250.0), fov = 70.0 },
            { label = 'Vault', coords = vec3(255.1, 228.6, 103.9), rotation = vec3(-30.0, 0.0, 160.0) },
        },
    },
},

name

  • name: string
    • Unique and lowercase. Used in the hostnames: bank-nvr01, bank-cam01.

label

  • label: string
    • The building's name.

coords

  • coords: vector3
    • Where the guard's computer is.

cameras

  • cameras: table[]
    • The cameras, in the order they are numbered (cam01 is 10.x.2.101).
    • label?: string
      • The name in the camera list.
    • coords: vector3
      • Where the camera is.
    • rotation?: vector3
      • vec3(pitch, roll, heading). Defaults to vec3(-15.0, 0.0, 0.0).
    • fov?: number
      • Field of view in degrees. Defaults to 60.0.

desktop, radius and screen

  • desktop?: this site's desktop. Defaults to the config's.
  • radius?: number: how close the player must be to the computer.
  • screen?: table: an in-world screen, like LC Hack's screens.

Placing Cameras

Stand where the camera hangs

Go to the corner of the room where the camera is, as high as you can, e.g. on a ladder or with noclip.

Note the coords and the heading

Your position is the camera's coords. Look the way the camera should look: your heading is the camera's heading.

Add the camera

{ label = 'Lobby', coords = vec3(240.2, 213.5, 110.5), rotation = vec3(-20.0, 0.0, 250.0), fov = 70.0 },

Start with a pitch of -20.0 (looking a little down) and adjust. A wider fov shows more of the room.

Check it

Restart lc_cctv, hack the site and view the camera.

Playing

Use the guard's computer

The shift notes on the desktop name the camera server (the NVR) and its web panel.

Find the NVR's login

Its web panel gives it away: in the page source (curl), in install notes it links to, or in a note on the guard's desktop (in base64, base64 -d).

Become root on the NVR

ssh admin@<nvr>. The camera list is root only; the root password is on the NVR (a config, the program itself with strings, or the shell history). An old one is there too.

Read the camera list

cat /etc/nvr/cameras.conf lists every camera with its IP and password.

Watch the cameras

view <ip> for each camera, with its password. Click a window to make it live. More terminals help: open another one from the dock to keep working while you watch.

How it Works

  • Every site is an LC Hack terminal with target = false: the player watches until they close it.
  • The cameras are LC Hack machines with a camera field. LC Hack's view command and camera windows do the rest, see Desktops.
  • The cameras' firewalls only let the NVR in, and the camera list is root only on the NVR.
  • Every password stays on the server, including the cameras', and every attempt is checked there.
