LC Els

Repository Download

A standalone Emergency Lighting System. Emergency lights, sirens and an air horn for every emergency vehicle, synced to everyone nearby, without a framework or any per-vehicle setup.

Features

  • Standalone: no framework and no dependencies.
  • Works with every vehicle in GTA's emergency class, including custom ones. No per-vehicle config.
  • Emergency lights, three sirens (wail, yelp, priority) and an air horn.
  • Sirens and horn are synced over the network, and the sound comes from the vehicle.
  • The lights stay on when the driver gets out; the siren and horn stop.

Installation

Download the resource

  • Download the latest version and unzip it as lc_els.
  • Or clone the repository: git clone https://github.com/LAURIDS0/lc_els.git

Start the resource

ensure lc_els

Try it

Get in the driver seat of an emergency vehicle and press Q for the lights, then ALT for the siren. See Controls.

Common Issues

Problems that come up with LC Els, and how to solve them.

Nothing happens in a vehicle

  • Only the driver can use the lights and sirens.
  • With EmergencyOnly = true (the default), only vehicles in GTA's emergency class (class 18) work. Check the vehicle's class in its vehicles.meta, or set EmergencyOnly = false.

ALT doesn't start the siren

The siren needs the lights. Press Q first, then ALT. Holding R for a short wail works without the lights.

The siren stops when I get out

That is on purpose: the siren and horn stop when the driver leaves the vehicle, and the lights stay on.

A key does something else as well

The keys are GTA controls, so other resources may use the same ones (ALT is also the character wheel). Change them in Keys.

Config

Everything is in config.lua. It is loaded on both client and server. Restart the resource after changing it.

Keys

  • Keys: table
    • The GTA control IDs for each action.
    • lights: number
      • Toggle the emergency lights. Defaults to 44 (Q).
    • siren: number
      • Toggle the siren. Defaults to 19 (ALT).
    • cycle: number
      • Next siren, or a short wail while the siren is off. Defaults to 45 (R).
    • horn: number
      • The air horn while held. Defaults to 86 (E).
Keys = {
    lights = 44, -- Q
    siren = 19,  -- ALT
    cycle = 45,  -- R
    horn = 86,   -- E
},

EmergencyOnly

  • EmergencyOnly: boolean
    • true: only vehicles in GTA's emergency class (18) can use LC Els. false: every vehicle. Defaults to true.

Sirens

  • Sirens: table[]
    • The sirens, in the order R cycles through them. The first one is used when the siren starts and for the short wail.
    • name: string
      • A name for the siren.
    • sound: string
      • The game sound to play from the vehicle.
Sirens = {
    { name = 'WAIL', sound = 'VEHICLES_HORNS_SIREN_1' },
    { name = 'YELP', sound = 'VEHICLES_HORNS_SIREN_2' },
    { name = 'PRIORITY', sound = 'VEHICLES_HORNS_POLICE_WARNING' },
},

Horn

  • Horn: table
    • sound: string
      • The game sound of the air horn. Defaults to 'SIRENS_AIRHORN'.

Controls

The default keys. Only the driver of an emergency vehicle can use them. Change them in Keys.

KeyAction
QTurn the emergency lights on or off. Turning them off also stops the siren.
ALTTurn the siren on or off. Needs the lights on; starts on the first siren.
RSiren on: switch to the next siren. Siren off: a wail while held.
EAir horn while held.

Siren order

With the siren on, R goes through the sirens in the order of Sirens and starts over:

WAIL -> YELP -> PRIORITY -> WAIL

Leaving the vehicle

  • Getting out: the lights stay on, the siren and horn stop.
  • Getting in another vehicle: everything on the old one is turned off.

Events

LC Els has no exports. The driver's client sends the state to the server, and the server sends it on to every player, so everyone hears the siren from the vehicle. They are listed for debugging.

NameDirectionData
lc_els:lightStateclient to server to all clientsvehicleNetId, active
lc_els:sirenStateclient to server to all clientsvehicleNetId, active, mode (mode is the index in Sirens)
lc_els:hornStateclient to server to all clientsvehicleNetId, active

The server adds the sender's id when it forwards an event, so a client never plays its own siren twice.
