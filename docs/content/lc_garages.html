LC Garages

Repository Download

Public, job and personal garages for Qbox. Players park their own vehicles and take them out again from a garage zone. Ownership, garage and state are checked on the server against Qbox's player_vehicles table.

Installation

Install all resource dependencies

  • qbx_core
  • qbx_vehiclekeys
  • ox_lib
  • oxmysql

Download the resource

  • Download the latest version and unzip it as lc_garages.
  • Or clone the repository: git clone https://github.com/LAURIDS0/lc_garages.git

Start the resource

Start it after its dependencies in your server.cfg.

ensure ox_lib
ensure oxmysql
ensure qbx_core
ensure qbx_vehiclekeys
ensure lc_garages

Set up your garages

The garages are in config/garages.lua. A few public and job garages are included; change or add your own, see Garage. No database changes are needed.

Usage

Walk or drive into a garage zone and press E:

  • In a vehicle (as the driver): the vehicle is parked in this garage.
  • On foot: a menu lists your vehicles stored in this garage; pick one to take it out.

Common Issues

Problems that come up when setting up garages, and how to solve them.

"This vehicle is not registered as one of your owned vehicles."

Only vehicles in player_vehicles with the player's citizenid can be parked. Job vehicles and vehicles spawned by admins can't; use LC Job Garages for job vehicles.

The menu says I have no vehicles

A vehicle shows up only in the garage it was parked in, and only while it is garaged (state = 1). Vehicles that are out or impounded don't show.

"There are no free vehicle spawn points."

Every spawn point has a vehicle within SpawnClearRadius (default 3.0 meters). Move the vehicles, or add more spawn points.

[E] doesn't show in the zone

  • The text only shows for players with access to the garage.
  • Turn on Config.Debug to see the zone and check its position, size and rotation.

The zones are drawn in the world

Config.Debug is true in the default config. Set it to false.

Config

General settings are in config/config.lua, the garages in config/garages.lua (see Garage). Restart the resource after changing them.

Debug

  • Config.Debug: boolean
    • Draws the garage box zones in the world, to place them. Defaults to true; set it to false on a live server.

SpawnClearRadius

  • Config.SpawnClearRadius: number
    • How close (meters) another vehicle can be to a spawn point before the point counts as taken. Defaults to 3.0.

WarpPlayerIntoVehicle

  • Config.WarpPlayerIntoVehicle: boolean
    • Put the player in the driver seat of a vehicle they take out. Defaults to true.

GiveKeys

  • Config.GiveKeys: boolean
    • Give the player keys with qbx_vehiclekeys when the server has confirmed the vehicle. Defaults to true.

DefaultBlip

  • Config.DefaultBlip: table
    • Blip values every garage uses unless its own blip sets them.
Config.DefaultBlip = {
    sprite = 357,
    color = 3,
    scale = 0.8,
    shortRange = true
}

Garage

Every garage is an entry in Config.Garages in config/garages.lua. The key is the garage's name; it is stored in the garage column of player_vehicles, so don't rename a garage that has vehicles in it.

Config.Garages = {
    ['legion'] = {
        label = 'Legion Square Garage',
        type = 'public',
        blip = { enabled = true },
        zone = {
            coords = vec3(229.24, -787.12, 31.68),
            size = vec3(43.0, 55.0, 5.0),
            rotation = 340.0
        },
        spawnPoints = {
            vec4(221.02, -806.52, 29.34, 247.95),
            vec4(224.06, -799.02, 29.31, 249.65),
        }
    },
}

label

  • label: string
    • The name shown on the [E] text, the blip and the menu.

type

  • type: 'public' or 'job' or 'personal'
    • Who can use the garage, see Garage Types.

jobs

  • jobs?: table<string, number>
    • For type = 'job': the jobs that can use it and the minimum grade for each, e.g. { police = 0, bcso = 2 }.

citizenid

  • citizenid?: string
    • For type = 'personal': the one player who can use it.
  • citizenids?: string[]
    • For type = 'personal': several players who can use it. Use either citizenid or citizenids.

blip

  • blip?: table
    • The garage's map blip. Without it, the garage has no blip. Values that are left out come from Config.DefaultBlip.
    • enabled: boolean
      • Must be true to show the blip. false hides it, e.g. for job and personal garages.
    • sprite?: number
      • The blip sprite.
    • color?: number
    • scale?: number
    • shortRange?: boolean
      • Only show the blip on the minimap when close.

zone

  • zone: table
    • The ox_lib box zone players press E in. Turn on Config.Debug to see it.
    • coords: vector3
      • The center of the box.
    • size: vector3
      • Width, length and height.
    • rotation: number
      • The box's heading in degrees.

spawnPoints

  • spawnPoints: vector4[]
    • Where vehicles are taken out: vec4(x, y, z, heading). The first free point is used, in order.

Garage Types

The type of a garage decides who can use it. Access is checked on the client (for the [E] text) and again on the server for every park and every vehicle taken out.

Public

Everyone can use it.

type = 'public',

Job

Players with one of the jobs, at the minimum grade or higher.

type = 'job',
jobs = {
    police = 0, -- every police grade
    bcso = 2    -- bcso grade 2 and up
},

Players park and take out their own vehicles here. For vehicles that belong to the job, use LC Job Garages.

Personal

Only the listed players, by their Qbox citizenid.

type = 'personal',
citizenid = 'ABC123',
type = 'personal',
citizenids = { 'ABC123', 'XYZ789' },

Hide the blip of personal garages with blip = { enabled = false }.

How it Works

LC Garages uses Qbox's own player_vehicles table. It never creates or changes who owns a vehicle.

Parking

  1. The player must have access to the garage and be the driver.
  2. The vehicle must have a valid plate that belongs to the player in player_vehicles.
  3. The vehicle's properties are saved in the mods column, the garage in garage, and state becomes 1.
  4. Only when the database update has succeeded, the vehicle is removed from the world.

Taking a vehicle out

  1. The menu lists the player's vehicles in this garage with state = 1.
  2. When one is picked, the server checks again that it still belongs to the player and is still in this garage.
  3. The vehicle spawns at the first free spawn point with its saved properties.
  4. When the server has confirmed the vehicle, state becomes 0 and the player gets keys.

If spawning fails before the server confirms it, the vehicle stays in the garage.

Vehicle states

stateMeaning
0Out
1Garaged
2Impounded
