Things to try

The terminal
  • help lists every command
  • ls -la, cd, tree, grep, find
  • nano note.txt, cp, mv, rm
  • ifconfig, nmap 10.0.0.0/24, ping
  • Tab completes, arrow up shows history
The desktop
  • Open the terminal twice: every terminal has its own logins and history
  • Files, the text editor, the image viewer and the system monitor
  • The browser: northbank.com is an always-on server with a website
  • In the terminal: startx without a desktop, rdp to another one
The cameras
  • The passwords are in cameras.txt on the desktop
  • view 10.9.1.101 and so on: each camera opens its own window
  • Click a window to make it live; the others freeze on their last picture
  • In the game the live window shows the real camera; here it is a picture
